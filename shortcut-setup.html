双击背面 → 截图识别 → 导入 CashMesh

打开需要记录的支付详情页后，双击手机背面。快捷指令在手机本地识别截图文字，再打开本手机的 CashMesh 网页导入。不是后台自动监听，不会同步到电脑；首次运行可能需要允许截图、识别与打开网址。

创建快捷指令：CashMesh 截图记账

  1. 打开“快捷指令”，点“＋”，命名为“CashMesh 截图记账”。
  2. 添加操作 截屏／拍摄屏幕快照（Take Screenshot）。输入是当前屏幕，不是相册里的上一张图片。
  3. 添加 从图像中提取文本（Extract Text from Image），输入选上一步的“屏幕快照”。
  4. 添加 URL 编码（URL Encode），操作选“编码”，输入选“从图像中提取的文本”。只编码文字，不要编码整个网址。
  5. 添加 文本，输入以下网址。最后的“URL编码结果”必须插入上一步的变量，不要直接键入这几个字：https://famisty.github.io/CashMesh-Demo/#capture=【URL编码结果变量】
  6. 添加 URL，输入选上一步“文本”；再添加 打开 URL（Open URLs），输入选上一步 URL。

绑定双击背面

设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选择“CashMesh 截图记账”。这里选择快捷指令，而不是仅选择系统“截屏”。

演示前测试

先在快捷指令中手动运行一次，再测试双击背面。支付详情应尽量显示平台、交易日期、实付金额；信息完整时自动导入，不完整时打开小面板补充。重复导入同一识别文字或明确订单不会再次增加消费。月账单汇总只做核对，不作为一笔新的消费。

此页面是可逐步搭建的动作配置，不是已签名的一键安装快捷指令包；没有在你的 iPhone 上完成实机验收。请用脱敏截图先测试。
