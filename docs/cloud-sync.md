# 手机和电脑配对同步（待配置）

状态：Supabase 项目、私有数据表和匿名设备登录已开通。已通过真实云端双设备身份测试：一次性配对、新增、接收、修改、删除及直接读表拒绝。iPhone背面轻点动作仍需在实际手机验收。

## 开通

1. 在自己的 Supabase 账户中新建 Free 项目，保留默认数据库/API安全设置。
2. Auth → Providers / Sign In → Anonymous，开启匿名登录。浏览器会取得独立设备身份，不要求用户填写邮箱和密码。
3. 在 SQL Editor 执行 `cloud/schema.sql` 一次；这是新建表脚本，不要在已有生产表上重复运行。
4. 将项目 HTTPS URL 和 publishable key（旧版称 anon key）写入 `cloud-config.js`。两项均为公开连接配置。不要填写 service_role、secret key、数据库密码或用户会话令牌。
5. 部署后用两个独立浏览器/设备验证下面的流程。校验跨账本隔离、过期码、用后失效、断网恢复与删除。

## 6分钟视频中的演示段（约50秒）

- 0—10秒：手机打开日常记账，新建云端账本，点击“连接另一台设备”。电脑输入配对码。
- 10—25秒：手机打开一张演示订单详情，轻点背面两下。快捷指令截屏、提取文字并打开记账页，核对平台和实付金额后点击“保存记录”。本流程仍有一次人工核对，不宣传为全自动入账。
- 25—35秒：电脑记账页打开着，5秒内轮询接收新记录，明细、日统计和平台图表更新。
- 35—50秒：电脑返回主页面，点击“更新”，展示近30天预览和消费评估变化。主页面继续手动更新，不后台刷新。

配对码为16位字符，10分钟有效，只能成功使用一次。可在录制完成配对后使用此段画面，旧码无法再连接。不要录入真实银行卡或真实身份信息。

## 数据与恢复

- 云端只保存结构化字段；截图、原始识别文字及其指纹留在原设备。
- 当前浏览器保留本机副本、设备会话、同步队列和已知版本。离线操作联网后补传。
- 同一笔同时修改时暂停该笔同步，明确选择“保留本机修改”或“使用云端记录”；其他笔继续同步。
- 删除以云端删除标记传播，旧副本不能无提示覆盖新版本。
- 创建者可移除其他设备。已下载到被移除设备的本机数据不能远程抹除。
- 至少保留一台已连接设备，并定期导出备份。当前不提供邮箱找回；所有设备身份清除后，无法用过期配对码找回云端账本。
- 一本演示账本最多10000笔（含删除标记）、10台设备。Free项目闲置可能暂停，不承诺生产级可用性。
