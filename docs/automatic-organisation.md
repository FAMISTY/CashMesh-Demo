# 自动整理与异常处理

- PDF通用提取先规范页面旋转坐标；账号/卡号说明、账单期间、打印/下单时间与零金额行自动忽略，不进入交易队列。组合收入/支出金额列按实际正负号和明确列证据判断。
- PDF预览每行有删除按钮，操作列固定在右侧；支持移除明显非交易行、勾选已识别项和移除文件。
- Excel/CSV识别支付方式/付款方式字段。零钱、余额、储蓄卡、借记卡可识别为自有资金；花呗、信用卡等识别为信用。组合或证据不足仍保留未知。
- 未提供分类使用“未分类”，分类缺失不阻止收支确认。外部转账遵循明确收入/支出，只有明确本人账户划转才忽略净现金变化。
- 已核实自有资金的现金退款可以独立计入现金变化，不强制关联原交易；信用退款仍需关联，才可冲减相应还款义务。早于预测起始日的历史还款已含在期初余额，可正常入历史账。本期还款仍需核对计划以免重复。
- 页面展示异常原因分布，并提供按来源范围批量补充未知付款来源；需要用户明确确认，不覆盖已有现金或信用证据。
- 新版加载时自动整理已有交易；没有保存原付款方式的旧数据无法凭平台名推断资金来源，可按来源批量声明。原文件重传且交易单号匹配时会补充付款证据、方向与分类，不新增重复记录。

测试涵盖3500笔无分类但有明确零钱付款的交易自动确认、重传去重、历史数据整理、来源范围批量补充与信用证据保护、非交易行过滤、PDF逐行删除及导入DOM事件。通用PDF仍需更多银行脱敏样本验证，不代表兼容所有格式。
