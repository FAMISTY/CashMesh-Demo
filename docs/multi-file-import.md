# 多文件账单整理

一次最多20个文件，每个10MB，本批总计100MB。支持CSV（UTF-8/GB18030）、XLSX/XLSM第一张工作表。

1. 同时选择多个平台、多个年份的账单。
2. 每个文件有独立映射和平台/账户字段；同一账户跨年文件需填写相同来源名。
3. 确认后统一整理，按同一来源内交易单号去重，保留来源文件名。
4. 报告逐文件导入、重复和错误行；单文件解析失败不影响其他有效文件。
5. 合并数据用于交易列表、历史消费分类；显示整体日期覆盖范围。预测仍依赖期初余额和未来收支，不重复扣减历史账单。

跨平台交易不自动按同金额合并，关联银行卡扣款与支付平台消费仍需人工核对。不同账户应使用不同来源名。没有交易单号的记录不自动去重。退款原交易尚未导入时保留待确认。

当前在线GitHub Pages版在浏览器内解析文件，未上传至FastAPI。主后端尚未实现对应的批量上传端点，不应把此功能描述为已接入服务端。

回归验证：5份CSV导入、XLSX异构字段、跨年重复、跨来源相同交易号、文件来源追溯、坏文件隔离与数量/大小限制。
