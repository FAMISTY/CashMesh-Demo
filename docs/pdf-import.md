# 银行PDF上传（2026-10-31）

多文件入口支持CSV、XLSX/XLSM与文字版PDF混合选择，每批20份、每份10MB、总计100MB。PDF最多200页。

加密PDF通过PDF.js onPassword在页面内请求密码，支持错误密码重试与取消；不记录密码、不提交密码或账单到服务器。解析库、worker、中文CMap与许可证随仓库托管。

解析按页面文本坐标分行，优先识别日期、借方、贷方、金额和余额列，余额列不作为交易金额。没有可靠列信息且出现多个金额时保留空金额，不猜测。提取不是银行格式全面兼容承诺。

每份PDF显示提取原文和可编辑CSV候选表；必须对照原件核对，保留表头并勾选确认。日期或金额未补齐时阻止整份导入。未知资金来源仍在待确认队列；保留来源文件与页码。没有可提取文字或存在无文字页面时阻止完整导入并提示OCR，不假装支持扫描识别。

不执行PDF内嵌脚本，不渲染外部链接。调用destroy清理解密文档。PDF只在本页临时批次中保存提取原文；确认导入后清除临时批次，浏览器可选保存中只含交易和计划。

测试含合成未加密PDF、加密PDF、错误密码重试、取消、扫描页、借贷列、余额排除、多金额歧义，以及核对确认和无文字页拦截。Node测试不等于真实浏览器验收；尚需各银行脱敏样本适配和完整性核验。
