# PDF表格导入

支持批量混合Excel、CSV、文字版/加密PDF。文件和密码在浏览器处理。密码不保存。扫描页未接入OCR，未识别完整的页面会阻止将账单作为完整数据导入。

## 工商银行借记账户历史明细

使用页面viewport转换文字坐标，适配90度页面旋转；排除斜向水印，按交易日期列定位记录，再映射收入/支出金额、余额、摘要与对方户名。收入/支出金额是带正负号的单列，不按列名中的“支出”推断全列方向。余额不参与交易金额计账。页眉、账单期间和下单时间不作为交易。

本地真实样本已逐笔对照独立文本提取结果验证日期和金额；原始PDF、真实交易和坐标数据均未提交仓库。回归使用合成布局，覆盖旋转与非旋转、正负号、斜水印、元数据日期和余额排除。

## 列表与确认

PDF预览展示结构化表格，标明已识别与需核对。专用格式明确识别项默认勾选，可直接导入；只需编辑异常项的日期、金额、方向和交易对方。未勾选记录保留在当前待处理区，可修正后继续导入；不会重复导入前一批已识别项。通用PDF尚未匹配可靠表格时仍需核对，不能视为已兼容全部银行。

“提取成功”与“财务可确认”区分：退款缺原交易关联、还款缺义务关联时，字段虽已识别，仍进入财务待确认。普通工商银行借记交易资金来源为cash，分类默认为未分类，不要求仅为补分类而逐笔确认。

可生成ICBC-DERIVED前缀内部去重键：日期、精确时间、带符号金额、余额和交易对方组成。它不是银行原始交易单号；缺精确时间或余额则不生成。同一账户/来源名内重复上传可去重，不跨账户凭金额合并。
